This repository contains the final project for IT 6740 – Advanced Network Defense and Countermeasures. The project focuses on using unsupervised machine learning techniques to detect zero‑day network intrusions through behavioral anomaly detection. Traditional intrusion detection systems rely on known attack signatures, which makes them ineffective against new or previously unseen threats. This project explores how models such as Autoencoders, Isolation Forest, and One‑Class SVM can learn normal network behavior and identify deviations that may indicate malicious activity.

The final research paper included in this repository presents a complete academic analysis of these models, including their strengths, weaknesses, and performance across modern intrusion detection datasets such as UNSW‑NB15, CIC‑IDS2017, and Kitsune. The paper explains the methodology used to preprocess the data, extract relevant features, train the models, and evaluate their performance using metrics such as detection accuracy, false positive rate, and AUC scores. The results show that Autoencoders provide the strongest detection capability for complex anomalies, while Isolation Forest offers the best balance between accuracy and operational feasibility due to its low false positive rate and fast training time. One‑Class SVM demonstrated limitations in scalability and sensitivity to parameter tuning.

All project files, including the final paper, diagrams, code, and supporting materials, are organized within this repository to ensure clarity and reproducibility. The instructor has been added as a collaborator to provide full access to the project. This work demonstrates how machine learning can enhance modern network defense strategies and highlights the importance of adaptive, behavior‑based detection methods in identifying emerging cyber threats. The project also emphasizes the need for improved interpretability, reduced false positives, and hybrid detection approaches for real‑world enterprise environments.
